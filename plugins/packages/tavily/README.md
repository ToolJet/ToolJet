# Tavily Plugin for ToolJet

Provides Tavily AI search and web extraction capabilities directly within ToolJet queries.

## Operations Supported
- **Search**: Perform real-time web search optimized for LLMs and AI agents with domain filters and depth control.
- **Q&A Search**: Get direct, concise answers with source citations for conversational questions.
- **Extract**: Extract raw text and structured markdown content from one or multiple URLs.
