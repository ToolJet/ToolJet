id: create-user
title: "Create User"
---

<EndpointHeader method="POST" path="/Users" />

<ApiColumns>
<ApiLeft>

Creates an active user in the instance and adds them to the default workspace. The role comes from the ToolJet extension attribute `role` and defaults to `end-user`. Any `groups` must already exist as custom groups. ToolJet generates a random password and doesn't send an invitation email.

<ErrorsTable errors={[
  {"status":"400","description":"Invalid request body or missing required fields (e.g. userName)."},
  {"status":"401","description":"SCIM isn't enabled (`SCIM_ENABLED` isn't `true`), or the Authorization header is missing or invalid."},
  {"status":"451","description":"Your license doesn't include SCIM."},
  {"status":"404","description":"The user couldn't be created, for example because a user with the same email already exists in the instance."}
]} />

</ApiLeft>
<ApiRight>
