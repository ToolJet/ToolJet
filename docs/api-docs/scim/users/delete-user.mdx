---
id: delete-user
title: "Delete User"
---

<EndpointHeader method="DELETE" path="/Users/{id}" />

<ApiColumns>
<ApiLeft>

Archives the user in every workspace, the same as setting `active` to `false`. ToolJet doesn't permanently delete users over SCIM. Setting `active` back to `true` unarchives the user in the default workspace only.

<ParamsTable title="Path Parameters" params={[{"name":"id","type":"string","required":true,"description":"The unique identifier of the user.","in":"path"}]} />

<ErrorsTable errors={[
  {"status":"401","description":"SCIM isn't enabled (`SCIM_ENABLED` isn't `true`), or the Authorization header is missing or invalid."},
  {"status":"451","description":"Your license doesn't include SCIM."},
  {"status":"404","description":"User not found."}
]} />

</ApiLeft>
<ApiRight>

<RequestExample code={`curl -X DELETE "https://{your-domain}/api/scim/v2/Users/{id}" \\
    -H "Authorization: Bearer <SCIM_HEADER_AUTH_TOKEN>" \\
    -H "Content-Type: application/json"`} />

**Response:** `204`

</ApiRight>
</ApiColumns>
