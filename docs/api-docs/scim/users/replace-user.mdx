<EndpointHeader method="PUT" path="/Users/{id}" />

<ApiColumns>
<ApiLeft>

Replaces all attributes of a user. Attributes not included in the request body are reset to their default values or removed. If `role` isn't sent, the user's role is reset to `end-user`. The user's custom groups are replaced with the `groups` in the request, so a request without `groups` removes the user from all custom groups.

<ParamsTable title="Path Parameters" params={[{"name":"id","type":"string","required":true,"description":"The unique identifier of the user.","in":"path"}]} />
