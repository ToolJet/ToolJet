id: delete-group
title: "Delete Group"
---

<EndpointHeader method="DELETE" path="/Groups/{id}" />

<ApiColumns>
<ApiLeft>

Removes all members from the custom group and deletes it from the default workspace. The users aren't deleted. Built-in groups (`admin`, `builder`, `end-user`) can't be deleted.

<ParamsTable title="Path Parameters" params={[{"name":"id","type":"string","required":true,"description":"The unique identifier of the group.","in":"path"}]} />

<ErrorsTable errors={[
  {"status":"401","description":"SCIM isn't enabled (`SCIM_ENABLED` isn't `true`), or the Authorization header is missing or invalid."},
  {"status":"451","description":"Your license doesn't include SCIM."},
  {"status":"404","description":"Group not found."}
]} />

</ApiLeft>
<ApiRight>

<RequestExample code={`curl -X DELETE "https://{your-domain}/api/scim/v2/Groups/{id}" \\
    -H "Authorization: Bearer <SCIM_HEADER_AUTH_TOKEN>" \\
    -H "Content-Type: application/json"`} />

**Response:** `204`

</ApiRight>
</ApiColumns>
