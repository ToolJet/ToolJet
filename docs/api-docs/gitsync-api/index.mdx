# GitSync API

The GitSync API lets you programmatically manage the full lifecycle of ToolJet applications within your CI/CD pipelines. Configure git sync, push and pull app versions from GitHub, and automate deployments without touching the ToolJet UI.

Integrate these APIs into Jenkins, GitHub Actions, GitLab CI, or any other pipeline tool.

## Typical workflow

Here's the usual order you'll call these in:

1. **[Add Git Configuration](/api/gitsync-api/add-git-config)**: a one-time setup step that connects a GitHub App to your ToolJet organization.
2. **[Create App from GitHub](/api/gitsync-api/create-app-from-git)** or **[Sync and Pull App from Git](/api/gitsync-api/sync-pull-app)**: import a new app that's tracked in the repo, or pull the latest changes into one that's already linked.
3. **[Commit and Push App Version](/api/gitsync-api/push-app-version)**: send changes you made in ToolJet back to the repo.
4. **[Release App Version](/api/gitsync-api/release-app-version)**: mark a specific version as the live one.

A "GitHub App" is simply an integration you install on your GitHub repository. It grants ToolJet permission to read and write code on your behalf. You create it once in GitHub, then reuse it across all the steps above.

## Authentication

All requests require a `Basic` access token in the `Authorization` header.

```bash
Authorization: Basic <access_token>
```

## Base URL

```
https://{your-domain}/api/ext
```

## Endpoints

| Endpoint | Description |
|:---------|:------------|
| [`POST /organizations/git`](/api/gitsync-api/add-git-config) | Configure GitHub HTTPS git settings for an organization |
| [`POST /apps/{appId}/versions/{versionId}/git-sync/push`](/api/gitsync-api/push-app-version) | Push an app version to the configured GitHub repository |
| [`POST /apps?createMode=git`](/api/gitsync-api/create-app-from-git) | Create a new ToolJet app from a GitHub repository |
| [`PUT /apps/{appId}?createMode=git`](/api/gitsync-api/sync-pull-app) | Sync and pull the latest changes from GitHub for an existing app |
| [`POST /apps/{appIdOrSlug}/git-sync/release`](/api/gitsync-api/release-app-version) | Set a specific version as the live released version for an app |
