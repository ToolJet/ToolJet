## ToolJet AI vs ToolJet MCP

Both can create and modify apps. The difference is where you drive them from, which model does the work, and who bills you for it.

|  | ToolJet AI | ToolJet MCP |
| --- | --- | --- |
| **Where you build** | The AI chat inside ToolJet, in your browser | Your own coding agent, such as Claude Code or Codex |
| **What it does** | Generates and modifies apps, modules, queries, and code; answers questions from the docs | Creates and modifies apps, manages users, and queries your instance in natural language |
| **Which model runs it** | ToolJet Managed AI by default, or your own key via [BYOK](/docs/setup/tooljet-ai/bring-your-own-key) | Whichever model your AI client is already running |
| **What it consumes** | [ToolJet AI credits](/docs/build-with-ai/ai-credits) | [AI model tokens](#credits-vs-tokens), billed by your model provider |
| **Setup needed** | None, it is available out of the box | A personal access token and an [MCP server install](/docs/build-with-ai/mcp/setup) |

### Credits vs Tokens

Both are metered, but in different units and by different parties.

|  | ToolJet AI credits | AI model tokens |
| --- | --- | --- |
| **What it measures** | One standardized unit of AI processing per ToolJet operation | The raw text units a model reads and writes |
| **What consumes it** | Every AI action inside ToolJet: generating an app, editing a component, writing a query | Every exchange between your coding agent and the MCP server |
| **What the cost depends on** | Complexity of the operation and the conversation context ToolJet carries | The model, its reasoning effort setting, and the complexity of the request |
| **Who bills you** | ToolJet, against the monthly credits in your license plus any add-on credits | Your AI client's model provider, on your existing subscription with them |
| **Where to check usage** | Settings → Subscription, or the credit icon in the AI chat | Your AI client or your model provider's dashboard |
