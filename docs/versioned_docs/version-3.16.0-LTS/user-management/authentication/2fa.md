Two-factor authentication (2FA) adds an extra layer of security to your ToolJet login by requiring a time-based one-time password (TOTP) from an authenticator app, in addition to your email and password. ToolJet works with any TOTP authenticator app, such as 1Password, Google Authenticator, or Microsoft Authenticator.

:::info
Two-factor authentication applies only to accounts that sign in with a password. It doesn't apply to users who sign in through SSO.
:::

Users can turn on 2FA for their own account at any time from their profile settings. Super admins can additionally require every password-based user on the instance to set up and use 2FA.

## Enable Two-Factor Authentication for Your Account

1. Click on the settings icon (⚙️) on the bottom left of your dashboard.
2. Go to **Profile Settings**. <br/>
    (Example URL - `https://app.corp.com/nexus/settings`)
3. On the **Two factor authentication** card, click **Add app**.
4. Scan the QR code with an authenticator app, or if you can't scan it, copy the secret key shown below the QR code and enter it manually in your app.
5. Enter the 6-digit code generated by the app and click **Submit**.

Once confirmed, the card's status switches to **Active**, and you'll be asked for a code from your authenticator app every time you sign in with your password.

### Reset or Disable

- **Reset** - Opens the setup screen again, so you can scan the QR code or copy the secret onto a new device, then re-confirm with a fresh code. Use this if you're switching devices or reinstalling your authenticator app.
- **Disable** - Enter your current 6-digit code to turn off 2FA for your account.

## Enforce Two-Factor Authentication Instance-Wide

Role Required: **Super Admin**

1. Click on the settings icon (⚙️) on the bottom left of your dashboard.
2. Go to **Settings > Manage instance settings**. <br/>
    (Example URL - `https://app.corp.com/instance-settings/manage-instance-settings`)
3. Enable the **Two-factor authentication** toggle. <br/>
    This requires users to verify their identity with an authenticator app when logging in.
4. Click **Save changes**.

:::info
For self-hosted deployments, the `MFA_MASTER_SECRET` environment variable must be configured on the server before 2FA can be set up or enforced.
:::

Once enforced, any password-based user who hasn't set up 2FA yet is shown a QR code the next time they log in and must complete setup before continuing. Users who already have 2FA configured are simply asked for their next 6-digit code.

## Logging In With Two-Factor Authentication

After entering your email and password:

1. If 2FA is required and you haven't set it up yet, scan the QR code (or enter the secret key manually) into your authenticator app. Then, enter the 6-digit code it generates to finish setup and sign in.
2. If you already have 2FA set up, enter the current 6-digit code from your authenticator app and click **Submit**.

Can't access your authenticator app? Click **Trouble signing in?** on this screen for recovery guidance.

:::tip
Codes refresh every 30 seconds. If your code keeps getting rejected, check that your device's clock is in sync - authenticator apps rely on accurate time to generate valid codes.
:::

## Recovering Access

- **Workspace or instance users** - Ask your workspace or instance admin to reset 2FA for your account from the user management page, then set it up again from **Profile Settings**.
- **Super admin (self-hosted)** - If a super admin loses access to their authenticator app and can't sign in, run the following script on the ToolJet server to clear their 2FA:
    ```bash
    npm run reset-mfa -- --email admin@company.com
    ```
    This clears the 2FA status for that super admin account only. They can set up 2FA again from **Profile Settings** after logging back in.
