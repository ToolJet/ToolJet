ToolJet propose une variété d'options de configuration pour aider votre organisation à adapter la plateforme à ses besoins spécifiques. Cette section présente les principaux domaines de configuration pour votre organisation, notamment le branding, les plans d'abonnement, les options de déploiement et la gestion des workspaces, afin de garantir une expérience optimisée pour votre équipe.

## Options de déploiement et plans d'abonnement

ToolJet propose deux options de déploiement — **Self-Hosted** et **Cloud** — permettant aux utilisateurs de choisir le modèle qui répond le mieux à leurs besoins. En plus des options de déploiement, ToolJet propose une gamme de plans d'abonnement pour chaque modèle de déploiement, offrant diverses fonctionnalités et avantages. Consultez le guide **[Choisissez votre ToolJet](/docs/tj-setup/tj-deployment)** pour plus de détails.

## Instances et workspaces

Dans ToolJet, un déploiement auto-hébergé de la plateforme est appelé une **[instance](/docs/tj-setup/instances)**. Chaque instance fonctionne de manière indépendante, en conservant sa propre configuration, ses propres données et sa propre base d'utilisateurs. Au sein de chaque instance, les **[workspaces](/docs/tj-setup/workspaces)** offrent des espaces isolés pour différentes équipes ou projets, permettant aux utilisateurs de gérer efficacement les applications, les ressources et les contrôles d'accès.

## Branding de l'organisation

ToolJet propose une personnalisation via le **[marquage blanc (white labeling)](/docs/tj-setup/org-branding/white-labeling)** et la configuration d'un **[domaine personnalisé](/docs/tj-setup/org-branding/custom-domain)**, vous permettant d'adapter votre instance à vos directives de marque. Le marquage blanc garantit que la plateforme reflète l'identité de marque de votre organisation, tandis qu'un domaine personnalisé vous permet d'utiliser votre propre adresse web pour l'instance ToolJet.

## Serveur SMTP

De plus, ToolJet vous permet de **[configurer votre serveur de communication par e-mail](/docs/tj-setup/smtp-setup/configuration)** pour gérer des tâches telles que l'envoi d'invitations et de demandes de réinitialisation de mot de passe, facilitant une communication fluide au sein de votre équipe et avec les parties prenantes externes.
