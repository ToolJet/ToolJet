title: Opérations sur les nœuds
---

<br/>

Vous pouvez effectuer les opérations suivantes sur les nœuds :

### Error Handling

L'opération de nœud **Error Handling** dans les workflows ToolJet vous permet de définir différents chemins d'exécution selon qu'un nœud réussit ou échoue. Si un nœud s'exécute avec succès, le workflow poursuit son chemin de succès ; s'il échoue, le chemin d'erreur est déclenché, ce qui vous permet d'effectuer des actions personnalisées comme la journalisation, des notifications ou des nouvelles tentatives.

<img className="screenshot-full img-full" src="/img/workflows/nodes/error-handling.png" alt="Workflows Preview" />

### Copy

L'opération **Copy** vous permet de copier la configuration d'un nœud dans votre presse-papiers. Vous pouvez ensuite la coller dans une autre partie du workflow ou dans un autre workflow pour une réutilisation rapide.

<img className="screenshot-full img-full" src="/img/workflows/nodes/copy.png" alt="Workflows Preview" />

### Duplicate

L'opération **Duplicate** crée instantanément une copie du nœud dans le même workflow. Cela permet d'accélérer la création de workflows comportant des nœuds similaires, sans avoir à tout reconfigurer depuis le début.

<img className="screenshot-full img-full" src="/img/workflows/nodes/duplicate.png" alt="Workflows Preview" />

### Delete

L'opération **Delete** supprime un nœud et ses connexions du workflow. Utilisez cette option pour nettoyer les nœuds inutilisés ou obsolètes et garder votre workflow organisé.

<img className="screenshot-full img-full" src="/img/workflows/nodes/delete.png" alt="Workflows Preview" />
