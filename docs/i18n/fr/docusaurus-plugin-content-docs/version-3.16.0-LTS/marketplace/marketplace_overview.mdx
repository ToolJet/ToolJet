Le Marketplace ToolJet propose une collection de plugins qui étendent les capacités d'intégration de ToolJet. Ces plugins connectent ToolJet à des services externes tels que des fournisseurs d'IA, des bases de données, des plateformes cloud et des applications métier.

- **ToolJet Cloud** : tous les plugins sont préinstallés. Configurez les identifiants et commencez à les utiliser dans vos applications.
- **Self-hosted** : installez les plugins depuis le Marketplace, puis configurez les identifiants pour les utiliser.

<img className="screenshot-full img-full" src="/img/marketplace/overview/marketplace-v3.png" alt="Marketplace Overview" />

## Installer un plugin (self-hosted uniquement)

1. Cliquez sur l'icône **Settings** en bas à gauche du dashboard.
2. Sélectionnez **Marketplace** dans le menu.
3. Accédez à l'onglet **Marketplace** pour voir tous les plugins disponibles.
4. Cliquez sur le bouton **Install** de la carte du plugin souhaité. Une fois installé, le bouton devient **Installed**.

<img className="screenshot-full img-full" src="/img/marketplace/overview/all-plugins-v3.png" alt="List of All Marketplace Plugins" />

## Configurer les plugins

Après avoir installé un plugin (ou pour les plugins préinstallés sur ToolJet Cloud), configurez ses identifiants :

1. Allez dans l'onglet **Data sources** du dashboard.
2. Faites défiler jusqu'à la section **Plugins** pour voir les plugins disponibles.
3. Cliquez sur un plugin pour configurer ses identifiants de connexion.
4. Une fois configuré, le plugin apparaît dans le Query Panel lors de la création de nouvelles requêtes.

<img className="screenshot-full img-full" src="/img/marketplace/overview/installed-plugin-v3.png" alt="Installed plugins" />

{/* ## Updating a Plugin

## Supprimer un plugin (self-hosted uniquement)

:::warning
La suppression d'un plugin supprimera toutes les requêtes qui lui sont associées dans vos applications. Si des requêtes sont liées au plugin, vous devrez d'abord les supprimer avant de désinstaller celui-ci.
:::

1. Allez dans **Settings** > **Marketplace**.
2. Accédez à l'onglet **Installed**.
3. Cliquez sur **Remove** pour le plugin que vous souhaitez désinstaller.
