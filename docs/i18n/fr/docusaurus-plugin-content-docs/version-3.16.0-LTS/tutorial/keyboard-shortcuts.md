# Raccourcis clavier

Vous pouvez effectuer des opérations telles que copier et coller des composants, cloner des composants, supprimer des composants, annuler, rétablir, et plus encore, à l'aide de raccourcis clavier.


| Action      | Raccourci Mac       | Raccourci Linux/Windows |
|:------------|:-------------------|:-----------------------|
| Sélectionner tous les composants | `cmd + a` | `ctrl + a` |
| Copier le composant | `cmd + c`          | `ctrl + c`             |
| Couper le composant | `cmd + x`          | `ctrl + x`             |
| Coller le composant | `cmd + v`          | `ctrl + v`             |
| Annuler        | `cmd + z`          | `ctrl + z`             |
| Rétablir        | `cmd + shift + z`  | `ctrl + shift + z`     |
| Cloner le composant | `cmd + d`          | `ctrl + d`             |
| Supprimer le composant | `delete`           | `backspace`            |
| Désélectionner le composant | `esc`              | `esc`                  |
| Exécuter la requête | `cmd + enter` | `ctrl + enter` |
| Aperçu de la requête | `cmd + shift + enter` | `ctrl + shift + enter` |

Pour sélectionner plusieurs composants à la fois dans l'app-builder, maintenez simplement la touche shift enfoncée tout en cliquant sur chaque composant que vous souhaitez sélectionner.
