### 1. Engagements en matière de partage des données

Vos données métier sensibles, les informations de vos clients et vos jeux de données propriétaires restent protégés et sous votre contrôle.

**Sécurité des identifiants** : Nous ne partageons aucun identifiant de source de données (comme les mots de passe de base de données ou les clés API) avec nos serveurs IA ou des fournisseurs LLM tiers. Si vous êtes en auto-hébergement, ces identifiants ne quittent jamais votre déploiement. Si vous utilisez ToolJet Cloud, ces données ne quittent jamais nos serveurs sécurisés.

Nous utilisons plusieurs modèles d'IA d'Anthropic et d'OpenAI pour alimenter nos fonctionnalités de génération.

Lorsque vous utilisez explicitement nos fonctionnalités d'IA sensibles au schéma, nous partageons vos invites, les métadonnées de l'application (comme les composants d'interface) et les schémas de base de données (par ex., les noms de tables et de colonnes) nécessaires à l'IA pour comprendre la structure de vos données.

Ces données sont transmises de manière sécurisée et exclusivement dans le but de répondre à votre demande immédiate de génération d'application. Elles ne sont partagées en dehors de votre déploiement pour aucune autre raison.

### 2. Options de déploiement

Vous pouvez répondre aux exigences spécifiques de votre organisation en matière de sécurité, de conformité et de résidence des données tout en conservant le contrôle de votre infrastructure grâce à notre option de déploiement auto-hébergé.

Bien que nous utilisions actuellement des LLM basés sur le cloud (comme Anthropic et OpenAI) pour les fonctionnalités d'IA, ces intégrations peuvent être gérées ou désactivées par les administrateurs de l'espace de travail.

Si vous avez besoin d'un environnement strictement isolé (air-gapped), vous pouvez configurer une instance ToolJet distincte pour le développement, ou choisir de désactiver les capacités de lecture de schéma par l'IA afin de garantir qu'aucune donnée structurelle ne quitte votre réseau interne.

Le plan entreprise auto-hébergé de ToolJet offre une option pour déployer notre passerelle IA sur site avec vos propres clés LLM. Contactez hello@tooljet.com pour plus de détails.

### 3. Politiques d'utilisation des données

Vos informations propriétaires, vos processus métier et vos avantages concurrentiels restent exclusivement les vôtres.

**Politique de zéro entraînement** : Nous n'utilisons aucune donnée utilisateur, schéma de base de données ou donnée d'exemple pour entraîner, affiner ou améliorer nos modèles d'IA, et nous n'autorisons pas non plus nos fournisseurs LLM tiers à le faire. Vos données sont strictement utilisées pour faciliter le fonctionnement de la plateforme ToolJet.
