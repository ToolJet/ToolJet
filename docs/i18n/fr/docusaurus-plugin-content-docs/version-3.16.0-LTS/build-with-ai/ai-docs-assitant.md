**Learn with AI** est un assistant intelligent conçu pour vous aider à naviguer facilement dans la documentation de ToolJet. Que vous ayez besoin de réponses rapides, de guides étape par étape, ou d'explications de concepts, cet assistant fournit une assistance instantanée en résumant la documentation, en résolvant des problèmes, et en vous guidant à travers les bonnes pratiques.

Vous pouvez accéder à cette fonctionnalité en sélectionnant **Learn** dans le menu déroulant du chat IA. Il suffit de poser une question ou de décrire ce que vous recherchez, et l'assistant vous fournira la documentation et les informations pertinentes.

<img className="screenshot-full img-full"  src="/img/tooljet-ai/learn-with-ai/dropdown.png" alt="tooljet ai doc assistant" />
 
### Ce que vous pouvez faire avec Learn with AI

- Obtenir des conseils sur la configuration des workspaces, la gestion des utilisateurs et la configuration des rôles.
- Comprendre rapidement des sujets complexes grâce à des étapes claires et concrètes.
- Trouver des réponses aux questions courantes et résoudre efficacement les problèmes.
- Découvrir comment connecter des bases de données, des API et des outils externes.
- Découvrir les bonnes pratiques pour sécuriser vos applications.
- Vous familiariser rapidement avec les fonctionnalités clés et les bonnes pratiques de la plateforme.
