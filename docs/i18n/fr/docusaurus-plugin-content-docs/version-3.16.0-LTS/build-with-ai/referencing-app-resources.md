---

Lorsque vous travaillez avec le chat IA dans ToolJet, vous pouvez utiliser `@` pour référencer des composants et des requêtes spécifiques dans votre application. Cela permet à l'IA de cibler précisément ce que vous voulez créer ou modifier, plutôt que de le déduire uniquement du contexte.

## Façons de référencer les ressources de l'application

### Taper @ dans le chat

Tapez `@` directement dans le champ de saisie du chat IA pour afficher une liste des composants et requêtes disponibles dans votre application. Sélectionnez celui que vous voulez, et il sera épinglé à votre message. L'IA limite ensuite son action à ce composant ou cette requête précis.

- **Composants** : Référencez un bouton, un tableau, un formulaire ou tout autre composant pour demander à l'IA de le mettre à jour.
- **Requêtes** : Référencez une requête spécifique pour demander à l'IA de la modifier ou de s'appuyer sur elle.

<img className="screenshot-full img-m" src="/img/tooljet-ai/ref-app-resources/mention.png" alt="mentionner un composant/une requête dans le chat" />

### Sélectionner depuis le canevas ou le panneau des requêtes

Vous pouvez également mentionner un composant ou une requête sans taper dans le chat :

- **Pour les composants** : Sélectionnez un composant sur le canevas. Une option pour le mentionner dans le chat IA apparaîtra. Cliquer sur celle-ci ajoute la référence du composant au champ de saisie du chat. <br/>
    <img className="screenshot-full img-m" style={{ marginTop: '15px' }} src="/img/tooljet-ai/ref-app-resources/select-comp.png" alt="mentionner un composant/une requête dans le chat" />
- **Pour les requêtes** — Sélectionnez une requête dans le panneau des requêtes. De même, vous verrez une option pour la mentionner dans le chat IA. <br/>
    <img className="screenshot-full img-full" style={{ marginTop: '15px' }} src="/img/tooljet-ai/ref-app-resources/select-query.png" alt="mentionner un composant/une requête dans le chat" />

Cela est utile lorsque vous pouvez voir le composant ou la requête avec lequel vous voulez travailler mais que vous ne vous souvenez pas de son nom exact.
