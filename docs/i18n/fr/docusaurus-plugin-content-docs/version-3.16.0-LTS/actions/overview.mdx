Les actions définissent ce qui se produit lorsqu'un [événement](/docs/app-builder/events/overview) se produit dans une application ToolJet — exécuter une requête, afficher une alerte, naviguer vers une autre page, mettre à jour une variable, et bien plus encore. Elles peuvent être configurées de manière déclarative via un gestionnaire d'événements, ou invoquées de manière programmatique depuis une requête RunJS.
