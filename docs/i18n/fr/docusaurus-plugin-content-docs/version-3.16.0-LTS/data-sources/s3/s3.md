ToolJet peut se connecter à des buckets **Amazon S3** et effectuer diverses opérations sur ceux-ci.

## Connexion

Pour établir une connexion avec la source de données **Amazon S3**, vous pouvez soit cliquer sur le bouton **+ Add new Data source** situé sur le panneau de requête, soit naviguer vers la page **[Data Sources](/docs/data-sources/overview/)** depuis le tableau de bord ToolJet.

ToolJet permet de se connecter à AWS S3 en utilisant des **IAM Access Keys**, des **AWS Instance Credentials**, un **AWS ARN Role**, ou même la **Default Credential Provider Chain**.

### Clés d'accès IAM

Si vous utilisez des **IAM Access Keys**, vous devrez fournir les informations suivantes :

- **Region**
- **Bucket**
- **Access key**
- **Secret key**

**Note :** Il est recommandé de créer un nouvel utilisateur IAM pour la base de données afin de pouvoir contrôler les niveaux d'accès de ToolJet.

<img style={{marginBottom:'15px'}} className="screenshot-full img-full" src="/img/datasource-reference/aws-s3/iam-v4.png" alt="aws s3 IAM connection" />

:::info
ToolJet permet de surcharger les paramètres de connexion AWS S3 au **moment de l'exécution de la requête** lorsque les paramètres de connexion dynamiques sont activés pour la source de données.

Une fois activé, le **paramètre bucket** devient configurable directement dans le générateur de requêtes, ce qui permet de fournir les valeurs de bucket de manière dynamique au moment de l'exécution plutôt que de les définir de façon statique dans la configuration de la source de données. Cela élimine le besoin de créer des configurations de source de données distinctes pour chaque bucket lorsque les identifiants de connexion restent identiques, rendant les requêtes plus réutilisables et plus faciles à maintenir.
:::

### Identifiants d'instance AWS

Pour vous connecter à AWS S3 en utilisant les **AWS Instance Credentials**, sélectionnez **Use AWS Instance Credentials**. Cela utilisera le rôle IAM attaché à l'instance EC2 sur laquelle ToolJet est exécuté.

Pour accéder au service de métadonnées d'un conteneur ECS et de l'instance EC2, nous utilisons le paramètre WebIdentityToken, obtenu suite à une connexion réussie auprès d'un fournisseur d'identité.

<img style={{marginBottom:'15px'}} className="screenshot-full img-full" src="/img/datasource-reference/aws-s3/instance-creds-v4.png" alt="aws s3 Instance creds" />

### Rôle ARN AWS

Si vous utilisez un **AWS ARN Role**, vous devrez fournir les informations suivantes :

- **Region**
- **Bucket**
- **Role ARN**

<img style={{marginBottom:'15px'}} className="screenshot-full img-full" src="/img/datasource-reference/aws-s3/arn-role-v4.png" alt="aws s3 Arn role" />

### Chaîne de fournisseurs d'identifiants par défaut

Vous pouvez également utiliser la **Default Credential Provider Chain** pour la connectivité.

:::tip
Vous pouvez désormais vous connecter à **[différents hôtes S3 en utilisant des points de terminaison personnalisés](/docs/data-sources/s3/s3-custom-endpoints)**.
:::

## Interroger AWS S3

1. Cliquez sur le bouton **+ Add** du gestionnaire de requêtes situé dans le panneau inférieur de l'éditeur.
2. Sélectionnez la source de données **Amazon AWS S3** ajoutée à l'étape précédente.
3. Sélectionnez l'opération souhaitée dans le menu déroulant et saisissez les paramètres requis.
4. Cliquez sur le bouton **Preview** pour afficher un aperçu du résultat, ou sur le bouton **Run** pour déclencher la requête.

<img className="screenshot-full img-full" src="/img/datasource-reference/aws-s3/aws-S3-listOps.png" alt="aws s3 query" />

:::info
Les résultats des requêtes peuvent être transformés à l'aide de transformations. Consultez notre [documentation sur les transformations](/docs/app-builder/custom-code/transform-data).
:::

### Lister les objets d'un bucket

Cette opération récupère la liste de tous les fichiers présents dans votre bucket. Elle nécessite les paramètres suivants :

#### Paramètre requis

- **Bucket**

#### Paramètres optionnels

- **Prefix**
- **Max keys**
- **Offset**
- **Next Continuation Token**

:::info
**Next Continuation Token** <br/>
Pour lister les objets d'un bucket commençant par un caractère ou un préfixe spécifique, utilisez le paramètre **Offset**. Par exemple, si vous souhaitez lister tous les objets commençant par **a**, définissez le paramètre **Offset** sur **a**. De même, pour lister tous les objets commençant par **ab**, définissez le paramètre **Offset** sur **ab**. <br/>
Le **Next Continuation Token** permet de lister le prochain ensemble d'objets d'un bucket. Il est renvoyé par l'API lorsque la réponse est tronquée. Les résultats contiendront un **Next Continuation Token** si d'autres clés du bucket correspondent à la requête de liste. Pour obtenir l'ensemble suivant d'objets, définissez le paramètre **Next Continuation Token** et exécutez à nouveau la requête. <br/>
Les résultats se poursuivront à partir de l'endroit où le dernier listage s'est arrêté.
:::

### URL signée pour le téléchargement

Le propriétaire de l'objet peut, s'il le souhaite, partager des objets avec d'autres personnes en créant une URL présignée, à l'aide de ses propres identifiants de sécurité, afin d'accorder une autorisation de téléchargement limitée dans le temps.

#### Paramètres requis

- **Bucket**
- **Key**
- **Expires in**

<img style={{marginBottom:'15px'}} className="screenshot-full" src="/img/datasource-reference/aws-s3/s3-signedURL.png" alt="aws s3 signed download" />

### URL signée pour le téléversement

Les URL présignées sont utiles si vous souhaitez que votre utilisateur ou client puisse téléverser un objet spécifique vers votre bucket, sans avoir besoin de lui fournir des identifiants ou des autorisations de sécurité AWS.

#### Paramètres requis

- **Bucket**
- **Key**
- **Expires in**
- **Content Type**

<img className="screenshot-full img-full" src="/img/datasource-reference/aws-s3/s3-signedurlUpload.png" alt="aws s3 signed upload" />
