Utilisez la base de données hébergée par ToolJet pour créer des applications plus rapidement et gérer vos données facilement. La base de données ToolJet ne nécessite aucune configuration et vous offre une interface utilisateur puissante pour gérer vos données.

<img className="screenshot-full img-full" src="/img/tjdb/preview.png" alt="Base de données ToolJet" />

## Fonctionnalités

La base de données ToolJet vous permet de :

- **Maintenir des tables de données** dans une base de données sécurisée uniquement accessible au sein de votre organisation ToolJet.
- **Modifier, rechercher, filtrer et trier** les données à l'aide d'une interface de type feuille de calcul.
- **Utiliser l'éditeur SQL** pour écrire et exécuter des requêtes SQL complexes directement sur votre base de données ToolJet, offrant des capacités plus avancées de manipulation et de récupération des données.
- **Créer rapidement des applications et écrire des requêtes** pour interagir avec la base de données ToolJet, tout comme n'importe quelle autre source de données mais sans aucune configuration.
- **Exporter le schéma** de la base de données ToolJet vers un fichier JSON.
- Identifier de manière unique chaque enregistrement d'une table à l'aide des **clés primaires**, garantissant l'intégrité des données et permettant une interrogation et une indexation efficaces.
- Établir des relations entre les tables à l'aide des **clés étrangères**, vous permettant de créer des associations basées sur la clé primaire d'une table et de maintenir l'intégrité référentielle.

## Accéder à la base de données ToolJet

Une fois connecté à votre compte ToolJet, vous pouvez accéder à **ToolJet Database** depuis la barre latérale gauche du tableau de bord.

La base de données ToolJet est disponible aussi bien sur **[ToolJet Cloud](https://tooljet.com)** que sur un déploiement **[auto-hébergé](/docs/setup/)**. Vous pouvez gérer votre base de données et ses données à l'aide de l'**interface de l'éditeur de base de données**.
