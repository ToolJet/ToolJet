title: Edit User Details
---

Au niveau instance, les Super Admins peuvent modifier le nom d'un utilisateur ou le promouvoir au rôle de Super Admin. Un Super Admin a accès à tous les espaces de travail et hérite de toutes les permissions d'un admin d'espace de travail. Au niveau espace de travail, les admins peuvent mettre à jour les **[rôles utilisateur](/docs/user-management/role-based-access/user-roles)**, les **[groupes](/docs/user-management/role-based-access/custom-groups)** ou les **[métadonnées utilisateur](/docs/user-management/onboard-users/user-metadata)**.

## Mettre à jour le nom d'un utilisateur

Rôle requis : **Super Admin** <br/>

1. Cliquez sur l'icône des paramètres (⚙️) en bas à gauche de votre tableau de bord.

2. Allez dans **Settings > All Users**. <br/> 
    (URL d'exemple - `https://app.corp.com/instance-settings/all-users`)

3. Repérez l'utilisateur dont les détails doivent être mis à jour et cliquez sur le menu à trois points (kebab) situé à la fin de sa ligne.
    <img className="screenshot-full" src="/img/user-management/profile-management/user-details/edit-menu.png" alt="Edit User Details Menu" />

4. Sélectionnez **Edit user details**.

5. Mettez à jour le nom de l'utilisateur.
    <img className="screenshot-full img-s" src="/img/user-management/profile-management/user-details/edit-name.png" alt="Edit User's Name'" />

6. Cliquez sur **Update** en bas du tiroir.
