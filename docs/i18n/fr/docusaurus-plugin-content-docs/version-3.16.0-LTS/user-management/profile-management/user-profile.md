title: Profile Settings
---

Grâce aux **Profile Settings**, un utilisateur peut mettre à jour son nom, télécharger un avatar de profil ou changer son mot de passe. Suivez ces étapes pour effectuer des modifications :

1. Cliquez sur l'icône des paramètres (⚙️) en bas à gauche de votre tableau de bord.

2. Allez dans **Profile Settings**. <br/> 
    (URL d'exemple - `https://app.corp.com/nexus/settings`)

3. Sur la page Profile Settings, il y a deux sections :

    a. **Profile**
        - Mettez à jour votre nom, ou téléchargez une image pour l'avatar de profil.
        - Cliquez sur le bouton **Update** en bas de la section.

    b. **Change password**
        - Saisissez votre mot de passe actuel.
        - Saisissez et confirmez votre nouveau mot de passe.
        - Cliquez sur le bouton **Change password** en bas de la section.
