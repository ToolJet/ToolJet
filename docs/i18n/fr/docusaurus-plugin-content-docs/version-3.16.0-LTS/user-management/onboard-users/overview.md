ToolJet offre des options flexibles pour intégrer des utilisateurs et un processus simple pour les désactiver lorsque nécessaire.

## Intégration des utilisateurs

Les utilisateurs peuvent être ajoutés à ToolJet soit par invitation, soit par inscription.

### Inviter des utilisateurs

Les utilisateurs admin peuvent intégrer des utilisateurs en envoyant des invitations :
- **Individuellement** : Envoyez une invitation personnalisée à un seul utilisateur en saisissant son adresse e-mail. Pour des étapes détaillées, consultez le guide **[Invite User](/docs/user-management/onboard-users/invite-user)**.
- **En masse** : Téléchargez un fichier CSV contenant les détails des utilisateurs pour inviter plusieurs utilisateurs à la fois. Pour des étapes détaillées, consultez le guide **[Bulk Invite Users](/docs/user-management/onboard-users/bulk-invite-users)**.

Les utilisateurs invités recevront un e-mail pour rejoindre l'espace de travail ToolJet.

### Inscription des utilisateurs

Les utilisateurs admin peuvent activer la fonctionnalité d'inscription, permettant aux utilisateurs de s'enregistrer eux-mêmes. En partageant l'URL de connexion, les utilisateurs peuvent créer leurs comptes et rejoindre l'espace de travail sans avoir besoin d'une invitation. Pour plus de détails, consultez le guide **[Sign-Up Users](/docs/user-management/onboard-users/self-signup-user)**.

## Désactivation des utilisateurs

Pour désactiver des utilisateurs, les admins peuvent **[archiver](/docs/user-management/onboard-users/archive-user#steps-to-archive-user)** les comptes utilisateurs. Une fois archivé, l'accès de l'utilisateur à l'espace de travail/instance est désactivé tout en préservant ses données. <br/>
Les comptes archivés peuvent être **[désarchivés](/docs/user-management/onboard-users/archive-user#steps-to-unarchive-user)** à tout moment, restaurant l'accès et les rôles de l'utilisateur.
