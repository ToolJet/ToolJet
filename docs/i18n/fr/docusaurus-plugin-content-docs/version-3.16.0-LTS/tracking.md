<br/>

ToolJet ne stocke aucune donnée récupérée depuis les sources de données. ToolJet agit comme un proxy et les données provenant des sources de données sont envoyées à l'application client sans être stockées.

ToolJet suit des données d'utilisation anonymes telles que les chargements de page et les clics. **ToolJet ne suit que les événements et ne capture pas les données provenant des sources de données.**

Le suivi peut être désactivé en définissant la variable d'environnement `ENABLE_TRACKING` à `0`.
