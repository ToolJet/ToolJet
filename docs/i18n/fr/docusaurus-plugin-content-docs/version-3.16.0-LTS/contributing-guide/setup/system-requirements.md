Cette page détaille les exigences système pour configurer et exécuter ToolJet, à la fois pour les installations Docker locales et Bare-Metal. 

## Docker 

**Windows :**

Lors de la configuration de Docker Desktop sur votre machine Windows, assurez-vous de disposer d'au moins 16 Go de RAM pour des performances optimales.


**Mac :**

Pour les installations Docker sur les systèmes Mac, il est conseillé d'utiliser une machine avec 16 Go de RAM pour améliorer l'efficacité opérationnelle.


## Installation Bare-Metal

Pour ceux qui préfèrent une installation [bare-metal](/docs/contributing-guide/setup/docker) plutôt que Docker, un minimum de 8 Go de RAM est recommandé pour un fonctionnement fluide.

Avant de démarrer le processus d'installation, veuillez vérifier que votre système répond à ces exigences spécifiées. Il est essentiel d'adapter les spécifications du serveur en fonction des besoins particuliers de votre scénario de déploiement.
