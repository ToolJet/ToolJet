title: Pull Request Review Checklist
---

Utilisez cette checklist rapide pour repérer les problèmes courants et maintenir la cohérence de votre projet.

- Vérifiez l'orthographe et la grammaire à l'aide d'outils comme ChatGPT ou Grammarly.
- Assurez-vous qu'aucun problème de compilation ne survient en raison du formatage.
- Vérifiez que tous les titres h2 et h3 suivent la casse de titre (title case).
- Confirmez que chaque section commençant par un h2 dispose d'un padding-top de 24px.
- Testez les liens brisés, les images manquantes et tout code incorrect.
- Assurez-vous que les nouveaux liens internes utilisent des chemins de fichiers relatifs à la racine.
- Identifiez les opportunités de liens croisés pertinents.
- Assurez-vous que les modifications sont implémentées dans toutes les versions requises.
