Bienvenue dans le guide de localisation de ToolJet. L'objectif de la localisation est de rendre ToolJet facile à utiliser et proche de tous les pays, langues et groupes culturels en général. Sur cette page, vous trouverez des instructions sur la façon de contribuer à ToolJet via la localisation et de rendre ToolJet plus accessible pour toutes les régions.

## Ajouter des traductions

- Pour ajouter les traductions de votre langue dans ToolJet, vous devrez créer un nouveau fichier **languagecode.json** qui contiendra toutes les traductions des mots-clés dans votre langue, puis lister la langue dans le fichier **languages.json** pour que la langue apparaisse dans le tableau de bord de ToolJet.

- Allez dans le répertoire **frontend** situé à la racine de ToolJet, puis allez dans **assets**, et à l'intérieur d'assets, vous trouverez le répertoire **translations**. Vous devez y créer un nouveau fichier json dont le nom correspond au **code de langue**. Le code de langue doit suivre le [code ISO 639-1](https://en.wikipedia.org/wiki/List_of_ISO_639-1_codes).

  ```
  \frontend
  |--\assets
  |--\--\translations
  |--\--\--\languages.json
  |--\--\--\en.json
  ```

    <div style={{textAlign: 'center'}}>

    <img className="screenshot-full" src="/img/l10n/files.png" alt="files" />

    </div>

- Localisons ToolJet en **français**. Créez un nouveau fichier json dans le répertoire translations et nommez-le **fr.json**. `fr` est le code de langue pour le français.

- Après avoir créé le nouveau fichier, ouvrez le fichier **en.json** et copiez tout son contenu dans le nouveau fichier **fr.json**.

    <div style={{textAlign: 'center'}}>

    <img className="screenshot-full" src="/img/l10n/en.png" alt="files" />

    </div>

- Une fois la copie effectuée, vous pouvez commencer à ajouter les traductions des mots-clés en français.

- Une fois la traduction terminée, il vous suffit de lister la langue dans le fichier **languages.json**. Vous devrez ajouter un objet avec trois paires clé-valeur. **lang** - le nom de la langue que vous avez ajoutée, **code** - le code de la langue, et **nativeLang** - le nom de la langue dans sa langue native.

  ```js
  {
      "languageList":
      [
          { "lang": "English", "code": "en", "nativeLang": "English" },
          { "lang": "French", "code": "fr", "nativeLang": "Français" }
      ]
  }
  ```
