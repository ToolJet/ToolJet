The App Builder is where ToolJet applications are built and edited. An application is built in one of two modes: in the Visual Builder, components are placed on a canvas and connected to queries; in React Builder, the application is written in React and TypeScript. Both modes use the same datasources, queries, permissions and release process.

## Build Modes

The build mode is selected when an application is created, and the application keeps it.

## Use Cases

ToolJet applications are commonly used for internal tools such as:

* Inventory management system
* Purchase order tracker
* Customer onboarding portal
* Loan origination and underwriting tool
* Fraud detection dashboard
* Expense approval workflow
* Timesheet tracker
* Employee onboarding app
* Internal ticketing system
* Compliance reporting dashboard
* Sales pipeline tracker
* Digital asset management portal
