title: Directus
---

The Directus plugin connects ToolJet to a Directus instance using a static access token. It supports working with items, collections, fields, files, and users through the Directus API.

## Setup and usage

For connection instructions, supported operations, examples, and troubleshooting, see the [Directus data source guide](/docs/data-sources/directus).

## Security

The access token is a secret. Use a token with only the permissions required by your application and do not share it publicly.
