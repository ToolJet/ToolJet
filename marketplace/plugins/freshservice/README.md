# Freshservice Plugin

Marketplace plugin for Freshservice — connects ToolJet to the Freshservice IT Service Management platform.

## Authentication
- **Domain**: `yourcompany.freshservice.com`
- **API Key**: sent via HTTP Basic auth (key as username, `X` as password)

## Supported Operations

### Tickets
- List tickets, Get ticket, Create ticket, Update ticket, Delete ticket
- Add note to ticket, Reply to ticket (email reply)

### Requesters & Agents
- List requesters, List agents

### Assets
- List assets, Create asset

### Changes
- List changes

### Problems
- List problems

### Service Catalog
- List service catalog items
